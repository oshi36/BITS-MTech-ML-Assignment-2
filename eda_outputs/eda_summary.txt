7. Key takeaways for modelling
======================================================================
- 68 duplicate rows -> drop before splitting.
- No missing values -> no imputation needed.
- Moderate imbalance (6.8x) -> stratified split, macro-averaged metrics, MCC.
- Very different feature scales -> StandardScaler inside each model pipeline.
- Heavy multicollinearity -> expect Naive Bayes to suffer; tree and SVM less affected.
- BOMBAY clearly separable; DERMASON vs SIRA expected to be the main source of error.
